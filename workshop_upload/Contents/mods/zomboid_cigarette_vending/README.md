# Cigarette Vending Machines

Project Zomboid B42 mod to add cigarette vending machines, including new machines, cigarette items, and vending behavior.

## Structure

- `mod.info` — mod metadata for Project Zomboid.
- `media/lua/` — Lua scripts for client, server, and shared systems.
- `media/scripts/` — object and item definitions.
- `media/textures/CigaretteVending/` — textures for vending machines and UI.
- `media/models/` — optional models for vending machines.
- `media/maps/` — world spawn and map integration.
- `media/sounds/` — vending machine sound effects.
